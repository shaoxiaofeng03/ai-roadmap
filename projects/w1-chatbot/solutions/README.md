# solutions · 参考答案使用规则

1. **先自己写**。卡住 30 分钟以上，允许看对应文件的**注释和结构**，看完**合上重写**。
2. 写完后 diff 对照——**差异点才是学习发生的地方**，把"我的写法 vs 参考写法"的差异记一句到笔记。
3. 周日闭卷自测 `docs/06-quiz.md`，答案在 `quiz_answers.md`。
4. 周日复盘时 Claude 会 review 你**自己的**代码（不是 solutions），按生产标准提意见。

|---|---|
